# Project Bootstrap

## Purpose

Initialize a new project's durable memory.

## Instructions

When invoked:

1. Ask the user:
   - What are you building?
   - Who is it for?
   - What problem does it solve?
   - What does success look like?
   - Preferred technology stack?
   - Known constraints?

2. Create:

memory/
  project.md
  architecture.md
  roadmap.md
  status.md
  decisions.md

3. Populate:

project.md:
- vision
- users
- goals
- non-goals
- principles

architecture.md:
- stack
- deployment
- major components
- unknowns

roadmap.md:
- MVP milestone
- future milestones
- backlog
- ideas

status.md:
- current phase
- current goal
- next action

decisions.md:
- leave empty until decisions are made

4. Create or update CLAUDE.md:

Include:
- quick explanation for each of the memory files
- instructions that only the memory files created here should be used and no new files should be created for project tracking
- read memory files before work
- roadmap may include ideas that need to be fleshed out before implementation
- update status after work
- record important decisions

5. Summarize the created project model.
